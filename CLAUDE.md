# Prezium GmbH: сайт-каталог на WordPress

Контекст для Claude Code. Читай этот файл в начале каждой сессии.

## О проекте
- Компания: Prezium GmbH (слоган: «Der Sieg liebt Präzision»), премиальные отделочные материалы.
- Это электронный шоурум без корзины. В каждой карточке товара есть кнопка «Preis anfragen» (pop-up с формой: имя, email, телефон, комментарий; к заявке автоматически добавляется товар или артикул).
- Аудитория: частные клиенты (B2C) и архитекторы, дизайнеры, строительные компании (B2B).
- Первый язык сайта: немецкий. Архитектура должна позволять добавить английский и украинский.

## Структура сайта
Start, Katalog (Türen, Parkett, Fenster, Terrassendielen, Möbel, Licht, Sonstiges), Marken, Architekten & Designer, Über uns, Kontakt. Footer: Impressum, Datenschutz, Cookie-Einstellungen (требования Германии).

## Ключевые функции (по порядку реализации)
1. Тема, шаблоны: главная, архив каталога, карточка товара, страница бренда.
2. Тип записи «Товар» + таксономии «Bereich» (направление) и «Marke» (бренд) + поля: артикул, материал, размеры, отделка.
3. Поиск (название, бренд, артикул) и фильтры внутри разделов.
4. Pop-up «Preis anfragen» с автоматической подстановкой товара.
5. Регистрация для B2B (имя, компания, должность, email, телефон) с одобрением администратором; скачивания (PDF, прайсы, техдокументация, CAD/BIM) только после входа.
6. Мультиязычность, SEO (мета-теги, ЧПУ, sitemap), скорость (lazy load, WebP/AVIF).

## Дизайн
Архитектурный минимализм: крупные фото, много воздуха, строгая типографика, технические данные в аккордеонах и табах. Холодный серо-графитовый тон, бронзовый акцент. Референс: кликабельный прототип (prezium.html).

## Правила работы
- Код пишется в `wp-content/themes/prezium`. Без внешних конструкторов страниц.
- Тексты в шаблонах на немецком, в коде используй `__( 'Text', 'prezium' )` для будущих переводов.
- Всегда экранируй вывод (`esc_html`, `esc_url`, `esc_attr`).
- Не трогай чужие плагины и ядро WordPress.
- Перед крупным изменением коротко опиши план и жди подтверждения.
- Локальная среда: `docker compose up -d`, сайт на http://localhost:8080.
