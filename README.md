# Prezium: локальный WordPress на Docker (Windows)

## 1. Один раз: установка
1. Установите **Docker Desktop** с docker.com. При установке оставьте включённым WSL 2. Перезагрузите компьютер, если попросит.
2. Запустите Docker Desktop и дождитесь, пока в нём появится статус «Engine running».

## 2. Запуск сайта
Откройте PowerShell в этой папке (в проводнике: Shift + правая кнопка мыши, «Открыть окно PowerShell здесь») и выполните:

```
docker compose up -d
```

Первый запуск скачивает образы, это занимает несколько минут. Потом откройте http://localhost:8080 и пройдите установку WordPress: язык, название сайта, логин и пароль администратора. Для локальной среды подойдёт любой пароль.

## 3. Включение темы
В админке: Внешний вид, Темы, **Prezium**, Активировать. После активации зайдите в Настройки, Постоянные ссылки и нажмите «Сохранить», чтобы заработали адреса каталога.

## 4. Повседневные команды
- Остановить: `docker compose stop`
- Запустить снова: `docker compose start`
- Удалить всё вместе с данными: `docker compose down -v`

## 5. Работа с Claude Code
Откройте эту папку в Claude Code. Файл `CLAUDE.md` содержит описание проекта, Claude Code читает его в начале сессии. Правки темы в `wp-content/themes/prezium` сразу видны в браузере после обновления страницы.
